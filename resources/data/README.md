# Données des villes

`world-cities.json` est une extraction du jeu de données [World Cities](https://github.com/datasets/world-cities), construit à partir de [GeoNames](https://www.geonames.org/). Les données GeoNames sont publiées sous licence [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Le fichier utilisé par l’application regroupe les noms de villes par code pays ISO, supprime les doublons et conserve les noms fournis par la source. Les utilisateurs peuvent aussi saisir une ville absente de cette liste.
